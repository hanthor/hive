# Hive examples

Worked examples for operators building their own Hive policies, state backends, and project campaigns.

- [SQLite state backend](sqlite-state.md) — schema and query patterns for single-machine deployments that want SQL-backed state alongside or instead of beads.
- [ACMM policy fragments](acmm/README.md) — per-level ACMM policy references for L1-L6.
- [KubeStellar examples](kubestellar/README.md) — skill files, worker scripts, and Strategy Lab campaign configs used by the KubeStellar hive.
- [Agent policy examples](agents/) — role-specific policy prompts for common lanes.
- [Tuna OS fleet & custom personas](tuna-os/README.md) — custom personas, policies, and fleet configuration for the Tuna OS cloud-native desktop Linux ecosystem.
- [KubeStellar fixer case study](kubestellar-fixer.md) — full worked example of the fix loop in production.
