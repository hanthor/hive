- **Config validation now refuses to start a hive whose `governor.rotation.providers` override leaves an ACMM pack backend without a rotation rung** ([#14](https://github.com/tuna-os/hive/pull/14)). Every agent in the built-in ACMM level packs runs on `copilot`; if an operator sets `governor.rotation.providers` explicitly and the resulting provider set fronts no `copilot` backend (or any other backend a pack agent uses), `hive` exits at load time with `pack level N agent <name>: backend "copilot" has no rotation tier rung` instead of silently running those agents with no failover. Hives that leave `providers` unset get the built-in default set (which covers `copilot`) and are unaffected; a hive that overrides the list needs a `github: {class: subscription, backends: [copilot]}` entry (or whichever provider fronts the pack backend) to keep starting.
