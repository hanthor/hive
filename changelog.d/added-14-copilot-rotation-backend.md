- `github-copilot` is now a first-class provider-rotation backend ([#7](https://github.com/tuna-os/hive/issues/7), [#14](https://github.com/tuna-os/hive/pull/14)). Rotation ships a built-in provider set — `anthropic` (`claude`, `pi`), `openai` (`codex`), `google` (`agy`), `github` (`copilot`) and `deepseek` (`litellm`) — that applies whenever `governor.rotation.providers` is left unset, so an operator no longer has to spell out every provider to get a `copilot` agent covered by failover. The new `github` prober exchanges the hive's GitHub token against Copilot's `GET /copilot_internal/v2/token` endpoint; a 429 is the only exhaustion signal that rotates an agent off `copilot`, and every other outcome (missing token, 401/403/404, 5xx, timeout, unparseable body) fails open exactly as the other probers do, so a change to that undocumented endpoint degrades Copilot to "no rotation signal" rather than causing spurious rotations. The watchdog auth probe set gains the `github` provider. `copilot` credentials are also resolved from `GH_TOKEN` and `GITHUB_TOKEN` (in that order after `COPILOT_GITHUB_TOKEN`) and from the persisted `/data/copilot-token-pat`, so a hive that only has a plain GitHub token in its environment starts `copilot` agents authenticated instead of showing the needs-login badge.
